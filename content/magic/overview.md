# 核心理论：浮光光谱说

## 1 基本原理

魔法并非源于生物体内，而是一种客观存在的能量粒子。其本源是天幕之外某种高维能量的辐射。当这种辐射穿透世界边界时，会被浮光进行过滤，稳定，除杂，从而产生一种可被生物体吸收并重新编码的粒子，解构人将其称之为辉质，其同时具有粒子性与波动性。
辉质无处不在，但浓度不均。暴露在浮光下的区域浓度较高，长期不与外界发生物质交换的区域浓度较低，但是幅度不大。海拔更高的地方辉质浓度越高，但是由于能明显对施法产生影响的浓度差需要不小的高度差，因此在地面可以将辉质浓度近似为均匀。浮光异象期间，辉质浓度会短暂暴增 3~5 倍，这是后天觉醒的最佳时机。

生物体通过吸收辉质来释放魔法。
### 2 浮光光谱
解构人通过观测发现浮光并非单一白光，而是由多种不同频率的辉质波叠加而成。辉质波根据波长和频段可以分为许多不同的类别，而解构人们分类并总结出了体现方式差别最大的七种。这七种频率对应七种基础魔法属性：

| 光谱频段  | 魔法属性 | 特征  | 典型用法   |
| ----- | ---- | --- | ------ |
| 赤（低频） | 火    | 扩散  | 灼烧、爆炸  |
| 橙     | 岩    | 凝聚  | 岩壁、硬化  |
| 黄     | 雷    | 激发  | 麻痹、闪电链 |
| 绿     | 风    | 流动  | 风刃、迅捷  |
| 蓝     | 水/冰  | 塑形  | 冰墙、幻象  |
| 靛     | 暗影   | 侵蚀  | 影钉     |
| 紫（高频） | 光    | 显形  | 闪光、真言  |

而高阶魔法是多种频率的复合。一般来说，这类复合常常出现于相邻的频段之间，现在已知每两种频段之间都可以归类出一种复合频段。

| 光谱频段 | 魔法属性 | 特征   | 典型用法           |
| ---- | ---- | ---- | -------------- |
| 赤-橙  | 塑能   | 物质转换 | 将辉质短暂凝聚成可观测的物体 |
| 橙-黄  | 衡    | 改变作用 | 调节物体状态与受力关系    |
| 黄-绿  | 音    | 波动震荡 | 感知并控制波动传播      |
| 绿-蓝  | 空间   | 改变结构 | 短暂改变空间的拓扑结构    |
| 蓝-靛  | 治愈   | 重新塑形 | 去除不需要的组织并重新塑造  |
| 靛-紫  | 感知   | 获取信息 | 获取原本难以获得的信息    |
一般来说，能够显性表现出的魔法远不止这些。以上所述的十三种魔法仅仅是人们对于魔法表现的归纳性总结。对于更多频段的复合魔法属性，能够产生的变化会更多，但是因为出现太过稀少，因此还无法进行成体系的研究。况且，就算只有这十三种，也够人们耗费很长时间进行研究了。
### 3 辉质吸收的生物学基础

人类体内存在一种特殊的细胞器——**辉核**，位于线粒体附近，负责吸收、储存和释放辉质。

辉核的数量，质量，激活性均由基因决定，具有高度遗传性，与极小的突变性。双亲均拥有高密度被激活辉核则子女大概率继承，单亲有则概率约为 1/2，双亲均无则大概率子女也没有高密度被激活辉核。被激活辉核的密度决定了魔法强度，贵族的被激活辉核密度大约是平民的 3~5 倍。

**后天觉醒的原理**：浮光异象期间的高浓度辉质会刺激休眠的辉核重新活化，这可以让人体内的被激活辉核出现/密度提高，但是无法让辉核总量增多。因此本就没有高密度辉核的人无法通过后天培养强行提升魔法强度。

## 魔法释放机制

### 1 释放流程

1. 吸收：辉核从环境中吸收游离辉质（类似呼吸）
2. 储存：辉质以压缩态储存在辉核内，不同属性对应不同储存形式。
3. 编码：施法者通过精神指令将辉质编码为“弦”，再由弦组成特定法术。其中，简单魔法所需要的弦可能只有一到两条，但是复杂魔法所需的弦将更多，解构也更加复杂。咒语本质上是精神指令的声学辅助，魔法者熟练后可以脱离咒语进行施法。
4. 释放：编码后的辉质通过媒介（通常是手、法杖、魔导器等）释放

除了普通的释放法术外，施术者也可以不对辉质进行任何编码，仅控制其流动，释放等，从而达到类似掌控的效果。较为常见的有控火，控水，凝冰等。当不对辉质加以控制让其自然流出时，会形成类似法力失控的情况，此时辉质会被辉核完全释放，常常会构成破坏力/威力强大但毫无章法的攻击，不过也正因为没有规律所以更难预判。

### 2 施法限制

辉质容量：个体能储存的辉质总量有限，一般来说耗尽后需时间恢复。当然，解构人针对这一点研制出了可以短暂地大幅提升辉核活性的药剂，在短时间内极大提升辉核吸收辉质的速度，因此可以做到“补魔”的效果。有些生物本身的辉核活性较高，因此可以保持较好的持续性施法。

精神负荷：施放引导术/仪式术等较为复杂的魔法需要高度专注，复杂法术对精神消耗极大，过度施法会导致精神过载，常常会出现短时间的精神恍惚，这是因为大脑长时间对辉质与弦进行编码，会消耗大量精力。如果精神过载严重，可能导致晕厥。大脑在无法继续施法时会自我保护使意识晕厥，因此到目前为止除了施放禁术以外，没有出现过因精神过载而死亡的人。

属性亲和：在高浓度的某种辉质波下，该辉质波对应的魔法将会得到强化，需要该辉质波复合的复杂魔法也会得到强化。而若某种辉质波浓度较低，那么其对应的魔法将会被削弱。同时，每个人天生对某一种或几种光谱频率有较高亲和度，因此刻意引导一般无法改变后天觉醒获得的属性。

环境浓度：在辉质浓度低的区域，施法效率会大幅下降。这也是维吉亚矿区武装冲突中贵族私军不敢深入某些区域的原因。

### 3 法术分类
- 瞬发术：简单的魔法，构成其的弦一般只有不超过 $3$ 条，且结构简单，熟练后几乎可以仅凭本能释放。
- 引导术：较为复杂的魔法，构成其的弦一般从几条到上百条不等，结构较为复杂，需要施术者持续专注，时长不定。
- 仪式术：极为复杂的魔法，构成其的弦一般有数百条以上，结构极为复杂，远超一个人可以承受的量级。因此这类魔法往往需要多人协同配合释放，或者加以外界辅助。
- 附魔术：在物体表面刻上纹路，本质上是引导辉质自然形成弦，然后进行魔法的释放。目前的技术已经可以完成简单弦的编码，并且可以释放简单的瞬发术。这也是魔法科技的原理。
