# 社会派系
社会等级森严，流动较为困难。社会在多方博弈中形成制衡。
### 魔法贵族派系

| 派系 | 代表 | 核心主张 |
| - | - | - |
| **保守派** | 三大古老家族中其二 | 严格维持魔法血统优先，反对向商业巨贾让利，限制平民教育，强化银十字地位 |
| **改革派** | 一家古老家族，部分新兴贵族 | 有限度接纳商业巨贾联姻，允许平民（有魔法）晋升，主张与解构人合作 |
| **鹰派** | 武力强大的边境贵族 | 武力解决维吉亚争端，真理在大炮的射程之内 |
| **鸽派** | 商业关联深的沿海贵族 | 谈判分地，避免战争，与商业巨贾合作开发 |
保守/改革 与 鹰/鸽 不互斥。
### 商贾内部派系

| 派系 | 描述 | 核心主张 |
| - | - | - |
| **传统派** | 经营安瑟拉内部贸易的世家 | 避免与贵族正面冲突，通过借贷和联姻缓慢渗透 |
| **开发派** | 新大陆开发中崛起的商贾 | 激进投资，多与贵族合作 |
| **研究派** | 投资魔导科技研发 | 推动技术垄断，贩卖魔导器获取暴利，对宗教冷淡 |
面对贵族集体压价或赖账时会联合施压。
### 银十字派系

| 派系 | 描述 | 核心主张 |
| - | - | - |
| **守序派** | 老一辈神职人员，正在逐渐被削弱 | 严格敬拜浮光，反对解构人，要求银十字恢复裂穹之战前的权威 |
| **温和派** | 目前主导银十字，控制多数教堂 | 接受现状，与解构人有限合作，专注慈善救济以赢得民心 |
两派系存在教义分歧，公开保持一致。
### 解构人派系

| 派系 | 研究方向 | 对外态度 |
| - | - | - |
| **学院派** | 魔法理论研究，浮光光谱分析 | 谨慎遵守审批制度，避免招惹银十字 |
| **实用派** | 魔导器研发、后天觉醒研究、药水改良 | 积极与商业巨贾合作，产品化导向 |
| **激进派** | 秘密研究反浮光装置、禁魔药水等 | 与赤痕团有秘密接触，被银十字视为死敌 |
激进派被学院派和实用派视为“危险分子”，从内到外抵制并清理，一经发现会立刻清出组织，不过并没有法律禁止激进派的研究。
### 有魔法平民群体

| 群体 | 组织 | 核心主张 |
| - | - | - |
| **学院精英** | 校友会、学术社团 | 打破贵族垄断高级职位，按能力晋升 |
| **城市中产** | 行会、银十字教区 | 反对贵族过度压榨 |
| **农村小地主** | 地方关系 | 保护私有财产，反对贵族随意圈地 |
学院精英与城市中产互有往来，但学院精英更激进；农村小地主保守，常与当地贵族妥协。
### 无魔法平民群体

| 群体 | 组织 | 特征 |
| - | - | - |
| **城市工人** | 地下互助会、酒馆帮派 | 流动大，消息灵通 |
| **农民** | 村社、教区 | 生活稳定，多数信银十字 |
| **矿工/远航者** | 劳工队 | 暴富机会少但存在，赤痕团活跃区 |
| **手工艺人/小商贩** | 行会 | 努力维持生计，以一技之长谋取优越生活条件，有些过得比有魔法平民还舒服 |
城市工人与农民联系较少；矿工群体因维吉亚特殊环境更团结。赤痕团主要渗透城市工人和矿工。
# 主要社会冲突
### 信仰对立：银十字 - 赤痕团
两者对世界本质的认知根本对立。赤痕团会对银十字教堂、神职人员发动恐袭；双方在多个城市发生地下武装冲突。每年浮光异象期间，赤痕团会尝试破坏银十字的集体祈祷仪式。银十字长期悬赏并通缉赤痕团成员。
### 阶级固化：魔法贵族 - 平民
魔法具有高度遗传性，经过数百年便形成了具有较强魔法的“魔法贵族”，即使平民中拥有魔法的人也不少，但是魔法强度普遍较低。教育，医疗等领域“有魔法者优先”现象普遍，导致阶级不满。在安瑟拉表现明显，但维吉亚稍显模糊（比如因为发现矿脉而暴富），家族势力正在维吉亚试图复制安瑟拉的模式。即使解构人发现了“后天觉醒”的方法，能增加的阶级平等性依旧有限。
### 资源争夺：家族
维吉亚的贵金属矿脉和辉质矿矿脉开发成本高，各大家族都想抢先占地，雇佣兵互相破坏对方据点与矿脉发现地的武装冲突是常态，立法因为各大家族的争执而停滞。银十字试图调解签订停战协议，但脆弱的协议常被破坏。在安瑟拉也常有家族之间的暗杀，对抗等。
### 科学伦理：解构人 - 银十字
解构人对浮光与魔法的解构常常被银十字认为亵渎圣物，动摇信仰，实验有时候也会引发事故，从而引来银十字的公开谴责，因此会被禁止在某些区域进行研究（除特殊审批外）。但解构人研发的魔导科技又被社会广泛需求，国家与银十字便允许其存在，只是进行研究需要通过审批，目前解构人会尽量避免挑衅银十字的信仰底线。

安瑟拉几乎所有研究院都是解构人创立的，民众需要学习最基本的魔导论知识也是银十字，解构人与政府共同商议后决定。
